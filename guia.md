# Proyecto de Autenticación

Este es un proyecto simple de autenticación de usuarios en consola.

## ¿Cómo instalarlo?

1. **Clona el repositorio**:
   ```bash
   git clone https://github.com/Josh-1620/Unidad-de-pruebas.git
## Accede a la carpeta del proyecto:
```cd Unidad-de-pruebas```

## Restaurar dependencias:
```dotnet restore```

## Ejecuta el proyecto:
```dotnet run```
## Cómo funciona?
El sistema permite que un usuario se autentique ingresando su correo y contraseña en la consola. Verifica que el correo sea válido y simula un proceso de login.

## Características
Autenticación por correo y contraseña.
Verificación de formato del correo electrónico.
